# 🎵 NESTLE MUSIC BOT (บอทเพลงอัจฉริยะ)

ยินดีต้อนรับสู่ **Nestle Music Bot** บอทเพลง Discord สายพันธุ์ไทย ที่มาพร้อมกับระบบจัดการ Playlist ผ่านหน้าเว็บสุดล้ำ! ใช้งานง่าย เสียงคมชัด และไม่มีโฆษณากวนใจ

---

## ✨ ฟีเจอร์เด่น (Key Features)

*   **🎧 รองรับทุกแพลตฟอร์ม:** เล่นเพลงได้ทั้งจาก **YouTube, Spotify**, และ **SoundCloud**
*   **💻 ระบบ Web Dashboard:** จัดการเพลงผ่านหน้าเว็บได้ทันที (Drag & Drop) ไม่ต้องพิมพ์คำสั่งยาวๆ
*   **☁️ Cloud Playlist:** บันทึกรายการเพลงส่วนตัวของคุณไว้บน Cloud (แยกของผู้ใช้แต่ละคน)
*   **🔊 High Quality Audio:** ระบบเสียงคุณภาพสูง พร้อมบัฟเฟอร์กันกระตุก
*   **🇹🇭 ภาษาไทย 100%:** เมนูและคำสั่งเข้าใจง่ายสำหรับคนไทย

---

## 🛠️ คำสั่งใช้งาน (Commands)

### 🎵 ฟังเพลงทั่วไป
*   **/nestle `[ชื่อเพลง/ลิงก์]`** : สั่งเล่นเพลงหรือค้นหาเพลง
*   **/skip** : ข้ามเพลงปัจจุบัน
*   **/leave** : สั่งให้บอทออกจากห้องและหยุดเพลง

### 🌐 ระบบเว็บเพลย์ลิสต์ (Highlight!)
1.  พิมพ์ **/site** 👉 บอทจะส่งลิงก์ **"หน้าจัดลำดับเพลงส่วนตัว"** ให้คุณ
2.  กดลิงก์เข้าไปเพิ่มเพลง หรือลากสลับตำแหน่งเพลงตามใจชอบ
3.  กลับมาที่ Discord พิมพ์ **/playlish** 👉 บอทจะเล่นเพลงทั้งหมดที่คุณจัดไวัทันที!
